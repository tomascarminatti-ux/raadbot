## 2025-05-24 - Interactive Feedback and Power User Shortcuts
**Learning:** Providing immediate visual feedback for utility buttons (like 'Copy!') and supporting keyboard shortcuts (Ctrl+Enter) significantly improves the perceived responsiveness and efficiency of the dashboard for power users.
**Action:** Always include temporary visual states for clipboard operations and implement standard keyboard shortcuts for primary form actions.

## 2025-05-24 - Non-Obtrusive Overlays
**Learning:** Fixed position overlays (like 'Live Logs') can obscure critical interactive elements on smaller viewports. Providing a minimize/toggle feature prevents UI occlusion while keeping the information accessible.
**Action:** Implement collapsible or toggleable states for non-critical dashboard overlays to preserve screen real estate.
