## 2025-05-15 - Collapsible Live Telemetry Pattern
**Learning:** Fixed floating panels (like a live log terminal) in a data-heavy dashboard can obscure critical content. Making these panels collapsible while maintaining a clear "live" status indicator (e.g., a pulsing dot) allows users to regain screen real estate without losing context of background activity.
**Action:** Implement collapsible states for auxiliary floating UI components with clear ARIA labels and visual status cues.
