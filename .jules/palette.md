# 🎨 Palette Journal - Raadbot UX

This journal documents critical UX and accessibility learnings gathered while enhancing the Raadbot interface.

## 2025-05-24 - Enhancing Utility Interactions

**Learning:** Users often need to reuse system prompts in other tools. Providing a one-click 'Copy' button with immediate visual feedback ("Copied!") reduces cognitive load and confirms success without needing to check the clipboard manually. Additionally, power users benefit significantly from keyboard shortcuts (like Ctrl+Enter) for frequent actions like prompt refinement.

**Action:** Implement clipboard utility buttons with temporary success states and standard keyboard shortcuts for core interactions. Ensure all inputs have associated labels for screen reader compatibility.
