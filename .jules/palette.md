## 2025-05-13 - Accessibility and Interaction Improvements in Dashboard

**Learning:** Combining ARIA attributes (`aria-labelledby`, `aria-live`) with micro-interactions (copy-to-clipboard feedback) and keyboard shortcuts (`Enter` to submit) creates a significantly more professional and accessible experience for AI-orchestration tools.

**Action:** Always associate textareas with visible labels using `aria-labelledby`, implement visual feedback for utility buttons like "Copy", and ensure primary actions are accessible via common keyboard shortcuts.
