## 2026-08-21 - Textarea Keyboard Submission & High-Contrast Focus Rings
**Learning:** In dark-themed chat or prompt refinement control panels, multi-line `<textarea>` fields benefit from standard `Ctrl+Enter` / `Cmd+Enter` keyboard submission shortcuts accompanied by clear visual `<kbd>` hints, explicit `text-slate-200` input contrast, and accessible `focus-visible:ring-2` styling.
**Action:** Always complement multi-line text input fields with a `Ctrl+Enter` shortcut event listener, accessible `<kbd>` shortcut helper text, and high-contrast text and focus styling.
