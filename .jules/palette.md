## 2025-07-20 - Keyboard Navigation Support and Copy Feedback for System Prompt Viewer
**Learning:** Scrollable code viewers/containers like `<pre>` or log displays require explicit keyboard focus (`tabindex="0"`) and descriptive `aria-label` tags to guarantee accessible keyboard navigation and avoid "tab traps" or unannounced regions. Additionally, interactive text-copying actions benefit greatly from immediate textual and stylistic state-reset patterns (such as temporary green "Copiado" status resets triggered either by a 2-second timeout, module switching, or code refinements).
**Action:** Always add `tabindex="0"`, descriptive `aria-label` tags, and visible `:focus-visible` styling to all custom-scrolled content sections, and implement context-aware state reset hooks to keep copy indicators and similar persistent indicators completely fresh across active view changes.
