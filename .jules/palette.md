## 2025-05-14 - Collapsible Glassmorphism Sidebars/Drawers
**Learning:** For auxiliary data like live logs, a collapsible "glass" container provides a modern aesthetic while preserving screen real estate. Keyboard shortcuts (Ctrl+Enter) in textareas significantly improve the flow for "power users" of LLM interfaces.
**Action:** Always include aria-expanded and descriptive aria-labels when implementing collapsible UI components. Ensure smooth transitions using Tailwind transition utilities.
