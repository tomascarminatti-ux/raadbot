## 2025-05-14 - Visual Feedback and ARIA Live Regions
**Learning:** Combining immediate visual feedback (text/color shift) with ARIA labels for buttons, and using `aria-live="polite"` for asynchronous content updates (like chat history), significantly improves the perceived responsiveness and accessibility for users with assistive technologies.
**Action:** Always include ARIA live regions for async content containers and ensure icon-only or multi-state buttons have descriptive, dynamic ARIA labels.
