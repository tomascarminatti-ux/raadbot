## 2026-03-30 - Keyboard Shortcuts and Accessible Input Controls
**Learning:** Fixed-position overlay elements (like `#live-logs` at bottom-right) can easily block primary interactive forms (textareas and submit buttons) on sidebar/split layouts. Positioning fixed logs at `left: 270px` (adjacent to sidebar) keeps the primary chat controls completely visible. Additionally, adding `Ctrl+Enter` shortcut handlers to multiline prompt textareas with visual `<kbd>` hints significantly reduces friction for power users without requiring mouse clicks.
**Action:** When adding fixed status/log overlays, position them in non-interactive viewport regions (e.g. bottom-left of main content), and always pair multiline text input submissions with keyboard shortcut hints and explicit `aria-label` tags.
