## 2025-05-24 - Glassmorphism Overlay Pattern
**Learning:** Using the existing `.glass` class combined with Tailwind's `bg-black/20` for internal content areas creates a consistent, high-end "industrial" feel for overlay components like live logs.
**Action:** Always leverage the `.glass` class for any new floating or overlay UI components to maintain visual harmony with the Raadbot 2.0 design system.
