## 2025-05-15 - Improving Copy to Clipboard Feedback
**Learning:** For accessibility and immediate UX feedback, changing the button text (e.g., to "✅ Copiado") is more effective than a passive tooltip, especially on mobile or for screen readers.
**Action:** Always provide clear, temporary visual feedback for "copy to clipboard" actions.

## 2025-05-15 - Sidebar Navigation Accessibility
**Learning:** Sidebar buttons with only text labels and icons are often missed by screen readers if not properly labeled with `aria-label`.
**Action:** Ensure all dynamic navigation elements have descriptive `aria-label` attributes.
