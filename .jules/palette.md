# Palette's UX & Accessibility Journal

## 2025-05-18 - System Prompt Copy & Character Counter UX
**Learning:** Monospaced prompt inspection views and free-form LLM refinement textareas require explicit feedback loops for optimal usability. Providing an interactive copy-to-clipboard button with visual/aria confirmation, a dynamic character counter, and keyboard submission shortcuts (`Ctrl+Enter`) dramatically enhances power-user flow and accessibility.
**Action:** When designing LLM control dashboards, pair copyable code/prompt blocks with icon feedback buttons and provide character limits with aria-live announcements for inputs.
