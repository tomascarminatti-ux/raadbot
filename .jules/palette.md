## 2024-05-26 - Keyboard Shortcuts and Auto-focus
**Learning:** Power users expect standard keyboard shortcuts (like Ctrl+Enter for submission) and appreciate reduced click-debt via auto-focusing interactive elements upon selection.
**Action:** Always consider adding keyboard shortcuts for terminal actions in LLM interfaces and use `element.focus()` when navigating between item selection and action input.

## 2024-05-26 - Collapsible Overlay Elements
**Learning:** Fixed position overlay elements (like live logs) can obscure main content on smaller viewports or complex layouts.
**Action:** Provide a toggle to collapse/minimize persistent overlay windows to allow users to reclaim screen real estate.
