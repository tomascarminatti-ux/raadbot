# Palette's UX Journal

## 2026-03-31 - Prompt Copy Feedback & Keyboard Shortcuts
**Learning:** In LLM orchestration dashboards with read-only prompt viewers, users frequently transfer prompt texts to external testing tools. Providing an immediate in-header copy button with multi-modal feedback (icon shift to '✅', green border tint, live ARIA label update) and an explicit keyboard shortcut indicator (`Alt+C`) significantly streamlines operator workflow without cluttering the code or UI.
**Action:** When adding quick utility actions to read-only text viewports, pair them with non-disruptive inline feedback states that revert after 2 seconds and include accessible tooltips for disabled states.
