## 2025-05-15 - [Collapsible Glassmorphism Telemetry Drawer]
**Learning:** For persistent monitoring tools (like live logs) in a glassmorphism dashboard, a collapsible drawer with Tailwind transitions and ARIA state management provides a balance between visibility and workspace focus. Using `aria-expanded` and a rotating chevron icon improves both accessibility and visual feedback.
**Action:** Use the `h-11` (collapsed) to `h-80` (expanded) transition pattern with `overflow-hidden` for similar side-drawers or overlays in this project.
