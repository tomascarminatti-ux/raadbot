## 2026-10-10 - Explicit Form Label and Ctrl+Enter Shortcut for Textarea
**Learning:** Multiline prompt textareas in chat/refinement UI panels require explicit form `<label>` associations for screen reader clarity, alongside clear visual `<kbd>` keyboard shortcut hints (`Ctrl+Enter` / `Cmd+Enter`) to streamline user workflow without requiring mouse focus shift to submission buttons.
**Action:** Always provide `<label for="...">` with shortcut hints for chat-based text inputs in control panel dashboards.
