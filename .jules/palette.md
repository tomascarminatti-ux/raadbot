## 2025-05-22 - Improved Live Log Visibility and Accessibility
**Learning:** High-contrast, industrial aesthetics benefit from interactive "Live" indicators and clear keyboard focus states to maintain usability and security. Using textContent over innerHTML for log streaming is a critical security pattern for preventing DOM XSS in real-time dashboards.
**Action:** Always implement a collapse/expand toggle for persistent UI overlays and prioritize textContent for dynamic WebSocket updates.
