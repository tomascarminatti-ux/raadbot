## 2025-05-18 - Keyboard Submission Shortcuts and Visual Keyhints
**Learning:** Adding `Ctrl+Enter` / `Cmd+Enter` keyboard shortcuts to multi-line input textareas along with inline visual `<kbd>` hints significantly reduces friction for power users, while explicit `text-slate-200` ensures proper dark mode contrast against dark background inputs.
**Action:** Always combine keyboard event listeners with non-intrusive `<kbd>` UI badges and `aria-describedby` links to guide users on available accessibility shortcuts.
