## 2025-10-24 - Accessible Clipboard and Scrollable Containers in Vanilla HTML
**Learning:** In headless Playwright/browser testing environments, granting permissions explicitly (`context.grant_permissions(['clipboard-read', 'clipboard-write'])`) is required for testing navigator.clipboard functions. For scrollable containers (like `<pre>`, `<ul>`, or `<nav>`), keyboard accessibility demands `tabindex="0"`, descriptive `aria-label` attributes, and clear focus indicators like `focus-visible:outline-blue-500`. Labels in vanilla HTML templates must use `for` rather than `htmlFor` (React-specific) to correctly associate with form controls.
**Action:** When adding clipboard or scroll-based interactive elements, always write appropriate tests with granted context permissions, implement `tabindex="0"`, use semantic vanilla HTML attributes like `for`, and include focus-ring styles.
