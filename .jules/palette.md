## 2025-05-24 - Enhance Prompt interaction and accessibility
**Learning:** Providing immediate visual feedback for clipboard actions (e.g., changing button text to "¡Copiado! ✅") significantly improves user confidence. Additionally, reducing friction by auto-focusing inputs when a context changes (like selecting a GEM) makes the interface feel more responsive and "ready for work".
**Action:** Always include temporary visual states for utility buttons and consider auto-focusing primary action elements when a view state changes.
