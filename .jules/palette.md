## 2025-05-14 - [Collapsible Log Stream]
**Learning:** Overlays that block primary action buttons (like fixed position log windows) cause friction in industrial-style dashboards. Providing a toggleable, minimized state preserves the "live" feel while giving back screen real estate.
**Action:** Use a transition on `max-height` and `width` for smooth toggle animations that provide clear visual feedback without breaking spatial context.
