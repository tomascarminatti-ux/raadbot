## 2025-07-17 - System Prompt Clipboard Copy with Reset and Keyboard Navigation Context
**Learning:** When displaying long, read-only system instruction templates (like System Prompts) in an AI dashboard, users benefit immensely from a visible clipboard-copy utility. However, the clipboard utility must follow strict UX patterns: (a) disable itself when no document/template is active; (b) provide immediate visual feedback (e.g., transition to a green success badge displaying "Copiado") to confirm copy operations; (c) reset automatically after a short timeout (2s); and (d) reset immediately when the user switches document context (selecting a different GEM module) to avoid showing a stale "Copiado" badge for a new item. Additionally, making the read-only viewport keyboard-navigable (`tabindex="0"`, focus rings, and proper `aria-label`) ensures that assistive tech users can inspect long content easily.
**Action:** Always implement contextual copy-to-clipboard actions next to template viewports. Ensure state changes (selecting different items) reset any pending copy timeout/success feedback state. Add `tabindex="0"` and descriptive Spanish/local language ARIA labels to scrollable `<pre>` elements to prevent keyboard trapping or screen reader bypass.
