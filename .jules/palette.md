# Palette's UX Journal

This journal tracks critical UX and accessibility learnings for the Raadbot project.

## 2025-05-15 - Collapsible Utility UI
**Learning:** Auxiliary floating UI components (like log terminals) should be collapsible to maximize usable screen real estate while providing visual status cues (e.g., pulsing dots) to signal background activity without obscuring content.
**Action:** Use fixed, collapsible "glass" drawers for non-critical status streams.
