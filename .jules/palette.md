## 2025-02-14 - Scrollable Container Keyboard Focus and Clipboard Feedback
**Learning:** Scrollable containers containing rich content (such as system prompt viewers, chat histories, or live logs) are not keyboard-accessible by default because users cannot focus on them to scroll using arrow keys. Adding `tabindex="0"`, descriptive `aria-label` attributes, and clear focus indicators resolves this gap. Furthermore, copy-to-clipboard interactions must provide immediate, high-contrast visual feedback ("Copiado" in green) that resets after a standard timeout (2 seconds) or when changing the active GEM module.
**Action:** Always provide `tabindex="0"`, custom focus rings, and an `aria-label` for any scrollable block, and guarantee that interactive copy-to-clipboard actions have both immediate visual feedback and proper state resetting mechanisms.
