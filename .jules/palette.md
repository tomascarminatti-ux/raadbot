# Palette's Journal - Critical UX/Accessibility Learnings

This journal documents critical UX and accessibility learnings discovered during the development of Raadbot.

## 2025-02-12 - Initial Palette Journal
**Learning:** Providing immediate visual feedback for clipboard operations (e.g., changing button text to '¡Copiado!' and icon to '✅' for 2 seconds) significantly improves user confidence and perceived responsiveness.
**Action:** Use this pattern for all "Copy to Clipboard" actions in the dashboard.
