## 2026-06-17 - [Collapsible Log Stream & Focus Indicators]
**Learning:** Real-time log streams can be visually overwhelming and obstruct main UI tasks. Providing a collapsible "glass" container maintains visibility while allowing user control. Keyboard focus indicators (focus-visible) are essential for industrial dashboards where power users may navigate via keyboard.
**Action:** Always include a collapse/expand state for real-time monitoring widgets and ensure focus-visible rings are applied to all interactive elements for a11y.
