## 2026-05-03 - Visual Feedback for Clipboard Actions
**Learning:** Providing immediate visual feedback (icon change and text update) for clipboard actions significantly improves user confidence in the interaction, especially for critical data like System Prompts.
**Action:** Always include a success state (e.g., checkmark, "Copiado!") for copy-to-clipboard buttons and ensure they revert to the default state after a short delay (e.g., 2000ms).
