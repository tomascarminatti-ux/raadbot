## 2026-09-22 - System Prompt Copy Feedback
**Learning:** Adding interactive copy buttons for code/prompt blocks with instantaneous visual feedback ("✅ Copiado") and updated ARIA labels enhances usability for developers and accessibility for screen reader users without cluttering the interface.
**Action:** When adding copy-to-clipboard functionality to code blocks or system prompts, always include dynamic ARIA labels and disabled states prior to content availability.
