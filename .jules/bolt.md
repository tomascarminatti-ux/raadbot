## 2025-02-18 - MTime-backed LRU Caching for Prompt Templates and Contract Schemas
**Learning:** High-frequency File I/O operations when repeatedly reading prompt markdown files and contract JSON schema files during agent pipeline executions introduce significant latency (~0.85s for 10k reads). Using `@functools.lru_cache(maxsize=32)` keyed on filepath and filesystem modification time (`mtime = os.path.getmtime(path)`) eliminates disk reads on warm hits (~7.5x speedup for schema validation, ~4.5x speedup for prompt building) while guaranteeing immediate cache invalidation whenever prompt or contract files are updated on disk.
**Action:** For static or semi-static disk assets (prompts, schemas, templates) read during agent loops, implement `@functools.lru_cache` paired with `os.path.getmtime` to combine near-zero latency in-memory reads with automatic invalidation.
