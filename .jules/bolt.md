## 2026-02-23 - [In-memory mtime-based file caching with functools.lru_cache]
**Learning:** In-memory caching using Python's `@functools.lru_cache` is highly effective for heavy disk I/O and JSON parsing workloads like loading prompt templates or contract schemas. However, to guarantee cache correctness when files on disk are dynamically modified, the cache key must incorporate the file's modification time (`os.path.getmtime`). It is critical NOT to decorate the `mtime` retrieval helper itself with `lru_cache`, as that would cache the `mtime` forever and defeat the automatic invalidation.
**Action:** Always implement caching of disk-loaded assets with an `mtime` cache parameter to enjoy fast sub-millisecond execution while maintaining perfect data integrity and automated disk-modification tracking.
