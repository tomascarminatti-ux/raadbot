## 2026-02-21 - JSON Schema Compilation Bottleneck
**Learning:** In the executive candidate validation pipeline, JSON validation is invoked multiple times (once for each GEM output, across multiple candidate runs). Standard `jsonschema.validate` compiles the schema dynamically on every call, leading to substantial overhead (~5.3 seconds for 2,000 iterations). By precompiling the schema using `jsonschema.validators.validator_for` on class initialization and reusing the compiled validator instance via `validator.validate()`, validation time dropped to ~0.36 seconds, yielding a ~14.6x speedup.
**Action:** Always pre-compile JSON schema objects when using Python's `jsonschema` library for repeated validation steps, and cache the compiled validator instance instead of calling standard `jsonschema.validate()`.
