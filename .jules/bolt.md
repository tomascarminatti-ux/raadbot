## 2026-07-19 - Caching and Single-Pass Substitutions for Prompt Building and Schema Validation
**Learning:** Repetitive disk I/O and JSON parsing are primary bottlenecks in multi-agent environments. Standard template rendering via nested loops of `.replace` calls compiles intermediate strings and wastes processor cycles. Utilizing `@functools.lru_cache` for template files and JSON schema definitions, pre-compiling regular expressions (`re.compile`) at the module level, and utilizing a single-pass `re.sub` substitution via a dictionary lookup callback results in dramatic performance gains.
**Action:** Always pre-compile regex patterns for replacement, cache read-only disk-bound files with `lru_cache` (with manual cache invalidation where files are modified dynamically), and consolidate multiple string replacements into a single pass using `re.sub` lookup callbacks.
