## 2024-03-05 - [Mtime-based LRU Cache for File System I/O]
**Learning:** For repeated file-based operations (e.g. loading prompts/templates from disk), using a `functools.lru_cache` wrapping an internal helper with the file path and `mtime` as arguments avoids repeated disk reads while ensuring instant cache invalidation if files are changed on disk. To avoid flakiness in unit tests that check `mtime` changes, explicitly manipulate timestamps with `os.utime` instead of using `time.sleep`, since filesystem modification time resolutions can be coarse (e.g., 1-second intervals on some filesystems/containers).
**Action:** Always implement `mtime`-based LRU caches for configuration/template loaders from disk, and use `os.utime` to explicitly modify file timestamps in unit tests.
