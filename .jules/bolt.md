## 2025-05-15 - Optimization of Prompt Construction Latency
**Learning:** Using `re.sub` with a callback for variable substitution is significantly more efficient than multiple `str.replace` calls when dealing with numerous template variables. Additionally, `lru_cache` for I/O operations like loading prompt templates provides a massive speedup (~4x in this environment), but requires explicit cache invalidation (`func.cache_clear()`) in API endpoints that modify the source files to avoid serving stale data. Benchmarking/testing scripts must use isolated temporary directories for file operations to prevent accidental corruption of production assets.
**Action:** Use single-pass regex substitution for template engines. Implement `lru_cache` for configuration/template loading. Always add cache invalidation in write paths. Ensure test/benchmark isolation using `tempfile`.
