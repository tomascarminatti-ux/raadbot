## 2026-08-02 - [Mtime-based LRU Cache for Prompt & Schema Loading]
**Learning:** In a multi-agent orchestration setup (like GEM 6), loading prompt templates and JSON contract schemas repeatedly from disk causes significant I/O overhead. Simple `lru_cache` can keep stale configurations. By using `functools.lru_cache` on helper functions and passing `os.path.getmtime(filepath)` as a parameter (cache key), we achieve automatic file-level cache invalidation as soon as files are updated on disk, without relying on manual resets or risking stale loads.
**Action:** Use `mtime` as a parameter of the cached reader functions `_load_prompt_cached(filepath, mtime)` and `_load_contract_cached(contract_path, mtime)` rather than decorating the `os.path.getmtime` itself, ensuring the mtime lookup always hits the disk while the heavier file read/parse operations are cached.
