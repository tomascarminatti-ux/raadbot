## 2025-02-18 - Input Validation & Path Traversal Mitigation in API Gateway
**Vulnerability:** Path traversal vulnerability via search_id, candidate_id, and gem_id in route parameters/JSON bodies. These fields were used directly to construct filesystem paths (e.g., using `os.path.join` or format strings) to load local files or save outputs without any sanitization or strict format validation.
**Learning:** Unsanitized string inputs used directly in filesystem operations can allow malicious actors to perform directory traversal and potentially access or write to arbitrary files. In FastAPIs, simple input type validation as `str` is insufficient to prevent path traversal when the input is used to build paths.
**Prevention:** Enforce strict regular expression checks on all identifier fields (such as `search_id`, `candidate_id`, and `gem_id`) that are mapped to the file system. In Pydantic v2, this can be securely enforced at the model parsing level using `@field_validator` with a regex pattern like `^[a-zA-Z0-9_-]+$`.
