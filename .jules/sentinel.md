## 2026-08-06 - Path Traversal Vulnerability in User-Controlled ID and Path Inputs
**Vulnerability:** Input parameters (`search_id`, `candidate_id`, `gem_id`, `local_dir`) were used directly in directory construction and file read/write operations (e.g., `os.path.join`, reading/writing prompts) without validation, enabling Path Traversal (CWE-22).
**Learning:** In APIs handling programmatic file creation or prompt refinement based on user inputs, lack of validation on identifier strings allows directories outside the intended workspace (such as system files or sensitive configurations) to be read or overwritten.
**Prevention:** Enforce input sanitization at the schema level using Pydantic `@field_validator` decorators. For identifier fields (`search_id`, `candidate_id`, `gem_id`), strictly reject path traversal sequences and separators (`..`, `/`, `\`). For directory paths (`local_dir`), normalize backslashes and disallow traversal sequences or absolute paths to containerize all actions within relative project directories.
