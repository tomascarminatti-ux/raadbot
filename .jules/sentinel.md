## 2024-07-27 - Input Validation to Prevent Path Traversal
**Vulnerability:** Path/directory traversal vulnerability via `search_id`, `candidate_id`, and `gem_id` in API endpoints. User input was used directly to construct filesystem paths (e.g., `os.path.join("runs", search_id, "outputs")`, `f"prompts/{gem_id}.md"`) without sanitization, allowing arbitrary file reading/writing on the host filesystem.
**Learning:** Security gaps often exist at integration and file boundaries when parsing request payloads into local paths. Even if the backend logic assumes identifiers are clean, without explicit endpoint schemas/validation, external systems or malicious requests can manipulate filesystem context.
**Prevention:** Always restrict identifiers (like IDs, folder/file names) to a strict alphanumeric and limited special character whitelist (e.g., `^[a-zA-Z0-9_-]+$`) at the API gateway or request schema parsing level. Use Pydantic's `@field_validator` decorator in FastAPI schemas to enforce constraints globally before payload validation finishes.
