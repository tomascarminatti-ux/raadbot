## 2025-05-18 - Path Traversal & Identifier Input Validation in API Request Models
**Vulnerability:** API request endpoints accepting `search_id`, `candidate_id`, `gem_id`, and `local_dir` parameters (`/api/v1/run`, `/api/v1/search/setup`, `/api/v1/gems/refine`) allowed path traversal sequences such as `..` or leading slashes. These inputs directly constructed file paths (e.g. `runs/<search_id>/outputs` or `prompts/<gem_id>.md`), enabling arbitrary directory/file access.
**Learning:** Pydantic models in FastAPI fail to restrict special characters unless explicit field validators or regex constraints are applied, allowing dangerous path inputs to reach file system functions (`os.path.join`).
**Prevention:** Always add Pydantic `field_validator` definitions on request parameters used to construct file paths, restricting identifier fields to strict alphanumeric regexes (`^[a-zA-Z0-9_-]+$`) and normalizing/disallowing path traversal sequences (`..`) or absolute paths on directory parameters.
