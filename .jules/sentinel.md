## 2026-08-08 - [High] Input Validation and Path Traversal Prevention in API Schema Fields
**Vulnerability:** Unvalidated parameter inputs like `search_id`, `candidate_id`, and `gem_id` used directly to form file paths (via `os.path.join` and `open()`), making the application susceptible to path/directory traversal and arbitrary file read/write vulnerabilities.
**Learning:** In multi-agent frameworks or file-system-backed configurations, user-supplied identifiers often serve as folder or file names on disk. Without validation at the API request parsing boundary (e.g., using Pydantic), malicious users can inject traversal strings (like `../`) or absolute paths, resulting in severe local file inclusion or data alteration.
**Prevention:** Implement strict alphanumeric checks (`^[a-zA-Z0-9_-]+$`) on all user-supplied folder or file identifiers and reject any folder path inputs (`local_dir`) that contain directory traversal patterns (`..`), absolute path markers (`/`), or Windows drive letters using Pydantic `field_validator`.
