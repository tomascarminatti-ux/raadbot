## 2026-08-10 - Path Traversal & Arbitrary File Access via API Parameters
**Vulnerability:** API endpoints accepting path identifiers (`search_id`, `gem_id`) and directories (`local_dir`) lacked input validation, allowing directory traversal sequences (e.g., `..`), absolute paths, and arbitrary file read/write access via Python file system operations.
**Learning:** Accepting direct file paths or identifiers that are concatenated into file paths without strict pattern validation allows attackers to traverse the file system, read/write configuration files, or inject malicious payloads. Relying on default models without strict parameter schemas creates easy local file inclusion (LFI) vectors.
**Prevention:** Always implement strict input validation at the model level (e.g., Pydantic `@field_validator`) to restrict identifiers to safe alphanumeric patterns (`^[a-zA-Z0-9_-]+$`) and normalize paths to reject traversal sequences (`..`), absolute prefixes, or unexpected drive letters.
