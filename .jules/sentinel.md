## 2025-02-15 - FastAPI Path Traversal via Unsanitized Request Identifiers
**Vulnerability:** API endpoints accepting parameters used directly in file paths (e.g., `gem_id`, `search_id`, `candidate_id`) were vulnerable to path traversal. A malicious user could supply payloads like `../../etc/passwd` to read or overwrite arbitrary markdown/json files on the filesystem.
**Learning:** The vulnerability existed because the Pydantic models for request bodies only typed these fields as generic `str` without applying format or character set constraints. Consequently, any string containing filesystem path separators was allowed to pass directly into `os.path.join` and file manipulation operations.
**Prevention:** Always apply strict format constraints to request identifiers using Pydantic `field_validator` or regex pattern fields (matching `^[a-zA-Z0-9_-]+$`). This ensures that only safe, bounded alphanumeric identifiers can ever reach filesystem-interacting layers of the application.
