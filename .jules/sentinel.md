## 2026-02-25 - Path Traversal Vulnerability in Identifier Fields
**Vulnerability:** Identifier fields (`search_id`, `candidate_id`, `gem_id`) in FastAPI request bodies were used to dynamically construct file paths for reading or writing files without any prior validation. Attackers could supply path traversal sequences (e.g., `../`, `../../etc/passwd`) to read or write arbitrary files on the system.
**Learning:** Constructing local filesystem paths (e.g., `runs/{search_id}/outputs`, `prompts/{gem_id}.md`) using unsanitized user inputs is highly vulnerable to path traversal. Even in internal or non-public APIs, input validation must enforce strict whitelists of allowed characters to prevent unauthorized path manipulation.
**Prevention:** Always validate identifiers used to build file system paths using strict regex patterns like `^[a-zA-Z0-9_-]+$`. Enforce this at the schema validation layer (such as Pydantic models with `field_validator`) to prevent unvalidated values from ever reaching path construction logic.
