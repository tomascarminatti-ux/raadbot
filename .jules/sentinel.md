## 2026-08-02 - Path Traversal Vulnerabilities in API Request Schemas
**Vulnerability:** API endpoints (`/api/v1/run`, `/api/v1/search/setup`, and `/api/v1/gems/refine`) accepted unvalidated `search_id`, `candidate_id`, `gem_id`, and `local_dir` input values, which were utilized directly in constructing file and directory paths. This allowed path traversal (e.g., using `..` sequences) to read, write, or overwrite arbitrary files on the system, which could lead to remote code execution.
**Learning:** Security controls on input parameters must be applied at the very entry point of the application (e.g. FastAPI/Pydantic schemas) to ensure untrusted input never reaches file path operations.
**Prevention:** Enforce strict alphanumeric-and-safe-symbol validation schemas (e.g., regex `^[a-zA-Z0-9_-]+$`) on all identifier strings used for path components, and aggressively validate/normalize directories to ensure they remain relative paths and do not contain traversal sequences.
