## 2025-05-24 - [Micro-UX: Copy to Clipboard Feedback]
**Learning:** Providing immediate visual feedback by changing button text and color after an action (like "COPY" -> "COPIED!") significantly improves user confidence in the interaction without requiring disruptive notifications like toasts.
**Action:** Use the "temporary state change" pattern for quick, non-critical actions to maintain a clean UI while ensuring clear interaction feedback.
